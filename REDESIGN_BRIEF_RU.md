# Бриф по редизайну лендинга

## Область проекта

Этот редизайн охватывает всю публичную часть текущего сайта:

- Главная страница
- Страница About
- Страница Contact
- Общий каркас layout (header + footer)
- Базовые переиспользуемые UI-примитивы, используемые на этих страницах

Текущий стек остается без изменений:

- Next.js App Router
- Tailwind CSS v4
- Существующие локальные изображения в public/images
- Текущая архитектура компонентов в src/app и src/components

---

## Цели редизайна

1. Сформировать узнаваемый премиальный B2B-образ для торговой компании (без шаблонного стартап-вида).
2. Улучшить визуальную иерархию и читаемость на всех страницах.
3. Сохранить знакомую структуру страниц, но сделать каждый блок визуально осмысленным.
4. Обеспечить качественную адаптивность для desktop и mobile.
5. Сохранить производительность и текущее поведение статического рендера.

---

## Варианты визуальной концепции

### Концепция A: Maritime Ledger

Тон:
- Стратегичный
- Надежный
- Представительский

Направление палитры:
- Глубокие navy-поверхности для фона
- Теплые песочно-ivory поверхности для контента
- Медный акцент для CTA и ключевых выделений

Направление типографики:
- Serif display для заголовков hero
- Чистый grotesk sans для текста и навигации
- Плотный, но дисциплинированный ритм заголовков

Направление motion:
- Медленные fade-and-rise анимации появления секций
- Мягкое поднятие карточек при hover
- Умеренный stagger только для сеток сервисов

Подходит для:
- Укрепления корпоративной надежности
- Премиального международного позиционирования


### Концепция B: Cargo Neon Grid

Тон:
- Смелый
- Технологичный
- Энергичный в логистическом контексте

Направление палитры:
- Графитовая база
- Кислотно-лаймовые и циановые акценты
- Бело-стальная иерархия текста

Направление типографики:
- Condensed display для ключевых сообщений
- Функциональный sans для основного текста
- Monospace микрометки для метаданных

Направление motion:
- Анимированные проходы grid-линий при загрузке секций
- Направленные переходы слева направо
- Короткие и четкие интеракции

Подходит для:
- Агрессивного нарратива про рыночную экспансию
- Сильной визуальной запоминаемости


### Концепция C: Atlas Light Industrial

Тон:
- Чистый
- Глобальный
- Операционно уверенный

Направление палитры:
- Светлые минеральные фоны
- Сланцевые и чернильные оттенки для типографики
- Ржаво-оранжевый сигнальный акцент

Направление типографики:
- Humanist sans с контрастом по насыщенности
- Крупная типографика для цифр и KPI-блоков доверия

Направление motion:
- Минимальный и спокойный
- Приоритет читаемости
- Анимация только там, где она усиливает иерархию

Подходит для:
- Сбалансированного современного вида
- Более консервативного, но заметно улучшенного бренд-восприятия

## Рекомендуемое направление

Основная рекомендация: Концепция A (Maritime Ledger).

Почему это оптимально для проекта:

1. Соответствует домену компании (глобальная торговля, надежность, длинный B2B-цикл доверия).
2. Избегает шаблонного dark SaaS-визуала, сохраняя премиальное ощущение.
3. Дает достаточный контраст между секциями без лишнего усложнения внедрения.
4. Быстро внедряется с текущими ассетами и существующей структурой компонентов.

## План редизайна по страницам

### 1) Общий Layout

Header:
- Превратить текущую верхнюю полоску в более чистый utility bar с сильнее выраженным ритмом отступов.
- Сделать основную навигацию sticky с полупрозрачной поверхностью и мягким backdrop blur.
- Улучшить состояния active/hover, чтобы они выглядели намеренно и в стиле бренда.

Footer:
- Ввести более четкую иерархию колонок и выразительную нижнюю юридическую плашку.
- Добавить компактные trust-блоки (время ответа, регионы работы, рабочее окно).

### 2) Главная страница

Hero:
- Заменить плоский overlay на многослойный градиент с направленной световой текстурой.
- Усилить типографический стек заголовка и добавить понятную пару primary/secondary CTA.

Блок About-preview:
- Перестроить в асимметричный split-layout с более выразительной рамкой изображения.
- Добавить одну краткую строку с метрикой для доверия.

Блок Services:
- Преобразовать однотипные карточки в более богатую систему с иконографикой и hover-состояниями.
- Ввести единые высоты карточек и контролируемую длину текста.

Блок Why choose us:
- Переформатировать в proof points с нумерацией.
- Добавить более явные визуальные якоря для быстрого сканирования.

### 3) Страница About

- Сохранить последовательность нарратива, но усилить контраст типографики.
- Перевести блок ценностей в более чистые карточки с визуальным разделением по категориям.
- Структурировать список экспертизы (колонки или сгруппированные chips) для более быстрого просмотра.

### 4) Страница Contact

- Сохранить простую структуру, но повысить визуальное качество.
- Усилить визуальное разделение между hero и карточками контактов.
- Улучшить ритм карточек и affordance состояний для email/action ссылок.

## Этапы внедрения

Этап 1: Дизайн-основа
- Перезапись токенов темы
- Настройка шкалы типографики и отступов
- Переработка каркаса header/footer

Этап 2: Главная страница
- Полное визуальное обновление секций главной
- Проверка адаптивности и читаемости

Этап 3: About и Contact
- Применение той же системы визуального языка
- Удаление точечных one-off стилей где возможно

Этап 4: QA и полировка
- Аудит отступов на mobile и tablet
- Тюнинг анимаций
- Проверка доступности (контраст, focus states, семантика заголовков)

---

## Критерии успеха

1. Все 3 страницы воспринимаются как единая визуальная система.
2. У сайта появляется узнаваемая идентичность вместо шаблонного вида.
3. Навигация и сканирование контента становятся проще на desktop и mobile.
4. CTA более понятны и визуально приоритизированы.
5. Нет регрессий по стабильности сборки и базовой производительности.
